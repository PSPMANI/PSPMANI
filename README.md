### About

I evaluate and improve AI systems for a living: I review how models generate code, catch where
they hallucinate or break, and build the rubrics and verifiers that keep output quality honest.
I write Python daily and reach for Java, C, Go, or TypeScript when the task calls for it.
I recently reviewed frontier AI at Scale AI (Outlier) and I am now open to new roles.

My focus: find the exact turn where a model breaks, and build the deterministic check that proves it.

### Featured Projects

Three public tools that show one idea - evaluation as a hard gate, not a vibe - from three angles.

| Project | What it does | Links |
|---|---|---|
| **TrajLens** | Agentic-trajectory auditor. Grades tool-use traces against a 9-criterion deterministic rubric (including safety checks for buried errors and unauthorized actions) and measures an LLM-judge against human labels with Cohen's kappa. | [Live](https://trajlens-mjh2vgfctsfyhrkulmtrxc.streamlit.app/) - [Code](https://github.com/PSPMANI/trajlens) |
| **JudgeLab** | Measures GPT-4-as-a-judge against 3,355 real human expert votes from MT-Bench: Cohen's kappa 0.46, a 15.8% order-swap inconsistency rate, and quantified verbosity bias. | [Live](https://judgelab-lzmmbppjsxunkqizxvrdvv.streamlit.app/) - [Code](https://github.com/PSPMANI/judgelab) |
| **EvalGate** | CI/CD pipeline that blocks bad models (GitHub Actions): tests, retrain, a hard ROC-AUC quality gate, artifact promotion, and an auto-deployed model dashboard. Running weekly, green for months. | [Live](https://pspmani.github.io/evalgate/) - [Code](https://github.com/PSPMANI/evalgate) |
